    Identify:¶

    We have a lot of the same constraints as the section of the scoring method

    Goals:¶

    • Fast (0.5 sec)
    • Reliable (no jamming)
    • No overheating issues under full match load
    • Score specific quantities of blocks (important for autonomous)
    • Color sorting
    • Fit under long goal
    • ~~Hold 12 blocks (6 in each chamber)~~ Hold 10 blocks (5 in each chamber) (other constraints)
    • Lightweight

    Size and shape¶

    In order for us to fit 6 (12 total) in a chamber we will want to look at how much liner space we need: A block has a maximum size of ~4 inches if we plan for worst case we would need (6*4=) 24 inches of chamber (worst case) If we look at the smallest distance (3.25 inches) we will need a minimum of 19.5 inches. Therefore, to fit 6 blocks we need the chamber(s) to have a 19.5-24 inch path length I drew out the design with some constraints, and there is a little problem: With the current constraints the easiest spot for the chambers to go is not long enough (understatement). With a path length of 17 inches the most blocks we could fit would be ~5.2 blocks which is useable.

    Levers¶

    We need a way to push the blocks out the front of the lever. My first idea is to use a pivoting c-channel (commonly used for lever bots) like this: It pivots up and pushes the blocks There is a little problem with this; the position of where it would need to pivot is really far forward and the way the PTO is setup right now is not ideal for this: It would be ideal to just use this pivot point, and i have an idea on how to do so. 4-bar lever: A 4-bar lift that has the horizontal bars attached on opposite sides to allow 180° of motion with a pushing "head" that stays facing one direction at all times. This has a great advantage as it lets us put the pivot point in the middle of the chamber as opposed to the front of the chamber. With this exact mechanism has a few problems with the angle of how it pushes the blocks (it would likely get stuck). A solution to this is to use a trapezoidal four-bar linkage instead of a normal 2 bar linkage where the top and bottom links are different lengths. this causes the angle of the "head" to rotate as it pivots.
